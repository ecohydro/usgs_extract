Metadata files — Column Descriptions
====================================
(rewritten 2026-11-19 for the switch to the new per-location metadata)

Which file to use
  data/analysis/evaluation/metadata/full_run/metadata_per_location.csv
      THE METADATA (Section 1). One row per location per table, 178,111 rows, from an
      open-weight language model (Qwen3.6-27B, prompt v5) reading each page
      (code/01_digitization/04_metadata_extraction/). Values are copied from the page as
      printed; location evidence that is not found on the page is dropped.
  data/analysis/processed_metadata.parquet
      Same rows (meta_row = row position) plus our checked and rebuilt fields
      (Section 2): water type, parsed dates, rebuilt locations, page types, measurement
      counts, reviewer corrections. Built by code/02_inventory/00a_metadata_base.py
      (-> data/analysis/metadata_base.csv) and 00_data_prep.py. Input to all analyses.
  data/catalog/restored_tables_catalog.csv
      One row per table, tribal pages removed; the file for data users
      (column key: catalog_key.txt).
  data/metadata/main_metadata.csv
      The earlier Phi-4 page-level metadata. NO LONGER USED (Annette, 2026-11-18);
      kept for reference (Section 4) and for its USGS document fields (Section 3).

Pages on federally recognized tribal lands are in metadata_per_location.csv and
processed_metadata.parquet but are withheld from publication
(code/02_inventory/12_tribal_lands_screen.py).

SECTION 1 — metadata_per_location.csv (the language-model metadata)
Accuracy on a 200-table test set (289 key rows; share right, 95% range):
code/01_digitization/04_metadata_extraction/README.md
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

doc_id, page_number, table_number
    USGS publication ID; page number in the scanned PDF (position in the file, not the
    printed page number); table number on the page (= the _tableN.csv suffix).

location_number, n_locations_in_table
    Location (site) number within the table; number of locations the table holds.
    Number of locations: 98% right.

location, location_type
    The best location evidence printed for this location, and its kind, by the
    hierarchy coordinates > well_number > station_number > station_name >
    township_range_section > named_place (place_name) > basin_or_area > county > state;
    none = nothing printed. Location 92%, location_type 94%.

coordinates, well_number, station_number, station_name, township_range_section,
place_name, basin_or_area, county, state
    Each kind of location evidence, copied as printed (blank if not on the page).
    county / state are as printed ("Calif.", "Santa Barbara County"), not standardized.
place_relation
    at / near / above / below / "3 miles north of" (goes with place_name).
evidence_place
    Where the best evidence is printed: in table | heading before table |
    elsewhere on page.

water_source
    Name of the river, creek, canal, lake, reservoir or spring; for a well, the owner or
    well name, as printed. 91%.

data_type
    The kind of water the SITE is on, not what was measured: Stream Discharge,
    Groundwater, Reservoir, Irrigation, Springs, Precipitation, Water Quality,
    Not Water Related, Other (also a few "Evaporation"). A stream station's temperature
    or chemistry table is Stream Discharge; a canal, ditch or diversion is Irrigation;
    "Water Quality" only when the page does not say what kind of water was sampled. 96%.

date_start, date_end
    First and last measurement in this table for this location, as fine as printed
    ("1916", "1916-10", "1916-10-01"). Water years run Oct-Sep (water year 1917 =
    "1916-10" to "1917-09"). Not the period of record, not the year a well was drilled.
    Full date 83% / 84%; start year 87%, end year 96%.

temporal_resolution
    daily | monthly | annual | discrete | no_time_series (definitions in catalog_key.txt).
    95%.

variables
    What the table records, ';'-separated: discharge, runoff, gage_height, contents,
    elevation, water_level, well_yield, temperature, sediment, water_chemistry,
    precipitation, evaporation; described: well_construction, lithology, water_use,
    irrigated_area; other. 92% exact, 98% overlap.

construction_date
    Wells only: year drilled or completed, as printed. 81% (of 19 key rows).

status
    ok | answer not readable | no answer for this table. The 131 tables without a
    usable answer are corrupted and cannot be rerun; they are excluded from the
    published set.

SECTION 2 — processed_metadata.parquet: added and rebuilt fields
One row per row of Section 1 (meta_row = row position). All Section 1 columns are
kept with their names, except as noted.
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

meta_row
    Row position (0-based); joins to the per-step outputs in
    data/analysis/location_validation/.
id
    = doc_id (name used by older scripts).
Title, Year Published
    From the USGS publication list (not from any language model).

--- WATER TYPE (00a_metadata_base.py) ---
water_type_clean
    data_type made to be one of the nine categories, with reviewer corrections applied
    (see review_action). Blank data_type: filled with the page's single other type, or
    by hand review; "Evaporation" -> Other, or Reservoir when measured at a reservoir.
water_type_source
    model | page_type | reviewer | evaporation | blank (no usable answer).

--- DATES (00a_metadata_base.py; date protocol of 2026-10-28) ---
year_start, year_end, decade_start
    Years of date_start / date_end. Valid years: 1800 to the document's publication year.
    A single date stands for both ends. year_start is filled only for dated rows.
date_status
    parsed | two_digit (YY-MM-DD read as 19YY) | trimmed (one end outside the valid
    years; replaced by the other end) count as dated.
    missing | unparseable | implausible (both ends outside the valid years) are undated.
    undated / construction_year: set by a reviewer (manual_review/).
construction_year
    First four-digit year of construction_date (wells only). Not a measurement date.

--- LOCATION (rebuilt; code/01_digitization/04_metadata_extraction/location_validation/) ---
A location is used only if its evidence is printed on the row's own page (a few
direction letters / meridians are settled from the same report: evidence_scope =
document). Model-guessed coordinates are never used.
lat_combined, lon_combined
    WGS84 point (blank when unlocated).
coord_method
    printed                 latitude/longitude printed on the page (printed value used)
    nwis_station, nwis_well NWIS station / well number printed on the page
    nwis_name, nwis_name_cluster
                            NWIS station name printed on the page without a number
                            (cluster = several gauges within 5 km, centroid)
    plss_section            township, range and section printed on the page
    plss_township           township and range only
    plss_wellno             California state well number (e.g. 10S/6E-23B1)
    wellno_group            several wells on the row, all within 5 km (centroid)
    gnis_*                  a named place on the page matched to USGS GNIS (2021 archive):
                            _qualifier_at / _feature_dam / _feature_reservoir (precise),
                            _qualifier_near / _above / _below / _place / _feature_lake /
                            _feature_spring (approximate); gnis_oos_* = outside California
    b118_basin, b118_subbasin
                            DWR Bulletin 118 groundwater basin named on the page (point
                            inside the basin polygon; for ~40 basins whose names resemble
                            another basin's, e.g. Santa Maria Valley / Santa Maria River
                            Valley, a county named for the row or on the page must overlap
                            the basin)
    unlocated               no usable location evidence on the page
precision_km
    Approximate uncertainty of the point (validated median error of the method).
precision_class
    precise      suitable for subwatershed (HUC12) work
    approximate  county / HUC8 scale
    basin        basin-level summaries only (point is a placeholder inside the basin)
    conflict     independent methods disagree (> 25 km, no agreeing majority) or a
                 named-place point is > 30 km from every NWIS gauge on the named stream;
                 coordinates kept but not used in maps or statistics
    unlocated
evidence_scope
    page | document (meridian or direction letters settled from elsewhere in the report)
location_check, n_sources, max_disagree_km
    Agreement of the independent location sources (printed / NWIS / PLSS / GNIS):
    agree | consensus | consensus_override (an agreeing group of >= 2 sources outvotes
    the top-ranked method) | conflict | single (one source).
stream_check_km
    GNIS points: distance to the nearest NWIS gauge on the stream the row names.
nwis_site_no, nwis_site_source
    NWIS site the location came from: number_on_page | name_on_page | name_cluster.
well_number
    State well number used for the location (rebuilt); well_number_printed = the
    model's well_number column (Section 1), renamed.
gnis_place, b118_basin
    Matched GNIS place / Bulletin 118 basin, when used.
row_class, row_states, page_state_class, page_states
    State evidence: ca | oos (the row's own place text or the metadata `state` field
    names another state; California-only references are skipped) | either (the page
    names another state, the row does not). page_state_class: ca | out_of_state | mixed.
watersource_name
    station_name if printed, else water_source.
new_location, townships_ranges_sections
    = location and township_range_section of Section 1 (names used by the location
    scripts).
continuation_rule
    Location carried from a continued table: not used (rule switched off 2026-11-18).

--- PAGE, MEASUREMENTS, REVIEW ---
page_type, is_data_page
    data | station_index (station catalogues: site information, no measurements; kept in
    volume figures, out of site analyses) | index_contents (indexes, tables of contents)
    | report_list (lists of earlier reports). is_data_page is False for index_contents
    and report_list.
matched_tables
    The row's own table number.
table_measurements, n_measurements
    Estimated measurements in the row's table (19_value_counts.py; definition in
    catalog_key.txt), and that count split evenly over the table's locations (sums
    over rows give table totals).
review_action
    Correction from a manual review of the page (data/analysis/manual_review/
    earliest_records_review.csv): retype (water type changed), set_year (year
    corrected), undate (no measurement date on the page), construction_year (the year
    is the year drilled; moved to construction_year), unlocate (location was wrong),
    keep (confirmed), drop (excluded from paper statistics only; data kept). Several
    can be combined with ';'. Blank if the page was not reviewed.

SECTION 3 — USGS Publications Warehouse document-level fields
In main_metadata.csv (cols 17-73) and the ID crosswalk USGS_ID.xlsx.
Source: pubs.usgs.gov. Same for every page of a document.
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

URL
    Direct URL to the document on the USGS Publications Warehouse
    (pubs.usgs.gov).

Publication ID
    Numeric USGS Publications Warehouse ID. Duplicates the id field for most
    documents; included here as exported from the warehouse.

Index ID
    USGS alphanumeric series identifier assigned at publication time
    (e.g., ofr5983, wsp1560a). Encodes the publication series and year.

Publication type
    Broad publication category as defined by USGS (e.g., "Report").

Publication Subtype
    More specific publication type (e.g., "Open-File Report",
    "Water Supply Paper", "Professional Paper").

Display title
    Formatted title as displayed on the USGS Publications Warehouse page.

Title
    Full document title as cataloged (may differ slightly from Display title).

Series title
    Name of the USGS publication series (e.g., "Open-File Report",
    "Water Supply Paper").

Series number
    Number within the series (e.g., "59-83", "1560-A").

Subseries
    Subseries designation, if applicable.

Chapter
    Chapter identifier within a multi-chapter publication, if applicable.

Sub-chapter
    Sub-chapter identifier, if applicable.

ISSN (online)
    International Standard Serial Number for the online version.

ISSN (print)
    International Standard Serial Number for the print version.

ISBN
    International Standard Book Number, if assigned.

DOI
    Digital Object Identifier (e.g., 10.3133/ofr5983).

Edition
    Edition number or descriptor, if applicable.

Volume
    Volume number for serial publications, if applicable.

Issue
    Issue number, if applicable.

Year Published
    Four-digit year the document was published.

No Year Published
    Flag indicating whether a publication year is unknown (TRUE/FALSE).

Language
    Language of the document (typically "English").

Publisher
    Publishing organization (typically "U.S. Geological Survey").

Publisher location
    City and state of the publisher.

Contributing office(s)
    USGS office(s) that produced the report.

Description
    Abstract or brief description of the document content.

Larger Work Type
    Type of the larger work this document is part of, if applicable.

Larger Work Subtype
    Subtype of the larger work, if applicable.

Larger Work Title
    Title of the larger work (e.g., journal or book title), if applicable.

First page
    First page number of this document within a larger work, if applicable.

Last page
    Last page number within a larger work, if applicable.

Number of Pages
    Total page count of the document.

Public Comments
    Any public-facing notes or comments added to the warehouse record.

Time Range Start
    Earliest date of the data covered in the document (YYYY or YYYY-MM-DD).

Time Range End
    Latest date of the data covered in the document (YYYY or YYYY-MM-DD).

Conference Title
    Title of conference, if this is a conference paper.

Conference Location
    Location of conference, if applicable.

Conference Date
    Date of conference, if applicable.

Country
    Country where the study was conducted (typically "United States").

State
    U.S. state(s) where the study was conducted (typically "California").

County
    County or counties covered by the document, as cataloged in the warehouse.

City
    City or cities referenced in the document.

Other Geospatial
    Additional geographic descriptors not captured by other fields.

Datum
    Geodetic datum used for any spatial data in the document, if specified.

Author(s)
    Full name(s) of author(s), semicolon-separated.

Editor(s)
    Full name(s) of editor(s), if applicable.

Compiler(s)
    Full name(s) of compiler(s), if applicable.

Number of Links
    Count of hyperlinks associated with the warehouse record.

ScienceBase URI
    URI for the document's record in USGS ScienceBase.

CHORUS DOI
    DOI registered with CHORUS (Clearinghouse for the Open Research of the
    United States), if applicable.

CHORUS URL
    URL registered with CHORUS, if applicable.

CHORUS Publisher
    Publisher name as recorded in CHORUS.

CHORUS Authors
    Author list as recorded in CHORUS.

CHORUS Journal Name
    Journal name as recorded in CHORUS, if applicable.

CHORUS Publication Date
    Publication date as recorded in CHORUS.

CHORUS Audited On
    Date the CHORUS record was last audited.

CHORUS Publicly Accessible Date
    Date the document became publicly accessible per CHORUS.

SECTION 4 — main_metadata.csv Phi-4 page-level fields (cols 1-16). NO LONGER USED.
Microsoft Phi-4 on the UCSB HPC cluster, one or more rows per page. Replaced by the
per-location metadata (Section 1) on 2026-11-18. The coordinate and date fields were
already superseded before that: many "actual" coordinates were not printed on the page,
and inferred coordinates were never validated. Kept for reference only.
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

id
    USGS Publications Warehouse Publication ID (numeric string). Serves as
    the document identifier and matches the folder name in data/digitized/.

page_number
    Page number within the document (integer, 1-indexed).

inferred_latitude
    Latitude (decimal degrees, WGS84) inferred by LLM Phi-4 from contextual
    clues on the page (location names, basin descriptions, nearby landmarks).
    May differ from actual_latitude if no explicit coordinates were reported.

inferred_longitude
    Longitude (decimal degrees, WGS84) inferred by LLM Phi-4 from contextual
    clues. Negative values indicate west longitude.

actual_latitude
    Latitude as explicitly reported on the page (decimal degrees, WGS84).
    Empty if no coordinates were printed on the page.

actual_longitude
    Longitude as explicitly reported on the page (decimal degrees, WGS84).
    Empty if no coordinates were printed on the page.

location
    Place name or description of the measurement location as extracted from
    the page (e.g., "Santa Ynez River at Solvang", "Goleta Valley").

townships_ranges_sections
    Township, range, and section information in Public Land Survey System
    (PLSS) format, if reported on the page (e.g., "T4N R26W S14").

watersource_name
    Name of the water body or feature as reported on the page — stream name,
    well identifier, reservoir name, spring name, etc.

actual_county
    County name as explicitly stated on the page.

inferred_county
    County name inferred by LLM Phi-4 from context (location descriptions,
    basin names, etc.) when not explicitly stated.

dates_of_recording
    Date range during which the data on the page was recorded, as extracted
    from the page (e.g., "1956", "January–December 1959", "1920–1950").

temporal_resolution
    Frequency of measurements reported on the page (e.g., "daily", "monthly",
    "annual", "instantaneous"). Empty if not determinable.

units_of_measurement
    Units in which the data values are expressed, as reported on the page
    (e.g., "feet below land surface", "acre-feet", "cubic feet per second").

water_type
    Water category assigned by LLM Phi-4. One or more of: Stream Discharge,
    Groundwater, Reservoir, Irrigation, Springs, Precipitation, Water Quality,
    Not Water Related, Other.

keyterms
    Key terms and phrases identified by LLM Phi-4 as most relevant to the
    page content. Stored as a Python list string (e.g., "['well', 'depth']").
