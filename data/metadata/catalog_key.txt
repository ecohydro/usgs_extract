restored_tables_catalog.csv / .gpkg — Column Descriptions
==========================================================
(rewritten 2026-11-19 for the catalog built on the new per-location metadata)

One row per digitized table (Reducto table CSV) in the published dataset.
Built by code/02_inventory/18_build_catalog.py.

Metadata source: the per-location metadata table produced by an open-weight
language model (Qwen3.6-27B) reading each page
(code/01_digitization/04_metadata_extraction/; one row per location per table).
Locations, water types and dates are then checked and rebuilt by our own steps
(described below). The earlier Phi-4 metadata is no longer used.

Included: tables in table_level_metadata_published.csv (tables with a usable
metadata answer; 131 tables whose answers were corrupted are excluded).
Excluded: pages on federally recognized tribal lands, withheld for tribal data
sovereignty (code/02_inventory/12_tribal_lands_screen.py). Out-of-California
tables are included and labeled (state, in_california).
The GeoPackage (layer "tables", EPSG:4326) holds the located rows only.

Size (2026-11-18 build): 97,321 tables, 61,421 pages, 583 documents,
17,472,473 estimated measurements.

File paths are relative to the root of the digitized data (one folder per
document, one subfolder per page).

IDENTITY AND FILES
  doc_id               USGS Publications Warehouse publication ID
  page_number          page number in the scanned PDF (position in the file, not the
                       printed page number)
  table_number         table number on the page (matches the _tableN.csv suffix)
  page_folder          {doc_id}/page_{N}
  table_csv            path of this table's CSV
  page_png             path of the page image
  page_json            path of the full Reducto output for the page
  has_png, has_json    whether the page image / JSON exists

DOCUMENT (from the USGS Publications Warehouse, not from any language model)
  doc_title, series_title, series_number, index_id, year_published, authors,
  usgs_url, doi

CONTENT
  water_type           Stream Discharge, Groundwater, Reservoir, Irrigation, Springs,
                       Precipitation, Water Quality, Not Water Related, Other.
                       The kind of water the SITE is on, not what was measured (a stream
                       station's temperature or chemistry table is Stream Discharge; a
                       canal, ditch or diversion is Irrigation). Per table: the type held
                       by most of the table's locations. Blank model answers were filled
                       from the other locations on the page or by hand review;
                       "Evaporation" became Other (or Reservoir when measured at a
                       reservoir). Reviewer corrections (manual_review/) are applied.
  water_type_source    single_type: all the table's locations have one type
                       majority: several types; the most common one
                       tie_first_location: several types, tied; the first location's type
  water_types_in_table all types among the table's locations (';'-separated)
  n_locations          number of locations (sites) the metadata lists for the table
  table_caption        table title found above the table by Reducto (may be blank)
  page_type            data | index_contents | report_list | station_index
                       station_index: station catalogues (name, number, drainage area,
                       periods of record) in the "Index of surface-water records"
                       volumes: site information, no measurements
  n_measurements       estimated number of measurements in the table: printed values of
                       a measured variable (discharge, gage height, contents, water level,
                       each water-quality result, ...). Not counted: dates, identifiers,
                       site descriptions (well depth, altitude), summary rows (totals,
                       means, maxima, minima) and columns computed from the table's own
                       values (runoff in acre-feet beside discharge, second-foot-days,
                       change in contents). "No flow" / "Dry" cells count. Rating and
                       capacity tables: every printed point counts.
                       (19_value_counts.py; an estimate from the digitized cells)
  watersource_name     name of the river, creek, canal, lake, reservoir or spring as
                       printed; for a well, the owner or well name (first location)
  location_text        the printed location evidence of the location used for the point
                       (coordinates, well number, station number or name, ...)
  location_text_type   coordinates | well_number | station_number | station_name |
                       township_range_section | named_place | basin_or_area | county |
                       state | none (the best kind of evidence printed for that location)

RECORD TYPE AND VARIABLES (from the metadata; most common value over the table's
locations / union of their variables)
  temporal_resolution  daily: a value for each day
                       monthly: one row or value per month
                       annual: one per year; also annual maximum/minimum tables, peaks
                         above a base, and stream rating tables
                       discrete: measurements on given dates (water levels, samples,
                         field measurements), also when about a month apart
                       no_time_series: well logs, inventories, capacity tables, undated
                         analyses
                       blank: not given
                       Test set (200 tables): 95% agree with the answer key (91-98%).
  variables            what the table records (';'-separated):
                       measured: discharge, runoff, gage_height (streams), contents,
                         elevation (lake / reservoir water surface), water_level,
                         well_yield, temperature, sediment, water_chemistry,
                         precipitation, evaporation
                       described: well_construction (depth, casing, diameter),
                         lithology (drillers' logs), water_use, irrigated_area
                       other
                       A quantity found only in total or summary rows is not listed.
                       Test set: 92% exact (88-95%); 98% overlap with the key.

DATES (first and last measurement in THIS table, from the metadata; then checked)
  year_start, year_end earliest start year and latest end year over the table's dated
                       locations. Water years are given as Oct-Sep (water year 1917 =
                       1916-10 to 1917-09, so year_start is 1916). Not the station's
                       period of record, not the year a well was drilled.
                       Valid years: 1800 <= year <= the document's publication year.
                       Test set: start year 87% (81-93%), end year 96% (92-99%).
  date_status          parsed: dated (at least one location dated; includes two-digit
                         years read as 19xx and ranges with one invalid end replaced by
                         the other)
                       missing: no date given
                       unparseable: a date that could not be read
                       implausible: both years outside 1800..publication year (undated)
                       undated / construction_year: set by a reviewer (manual_review/)
  construction_year_min, construction_year_max
                       wells only: years drilled or completed, as printed (not
                       measurement dates). Test set: 81% of 19 rows.

LOCATION (rebuilt from printed evidence; model-guessed coordinates are not used)
  latitude, longitude  WGS84 point (blank when unlocated)
  coord_method         printed (lat/long printed on the page), plss_section /
                       plss_township / plss_wellno / wellno_group (Public Land Survey
                       or state well number on the page), nwis_station / nwis_well (NWIS
                       number on the page), nwis_name / nwis_name_cluster (NWIS station
                       name, e.g. "Santa Ynez River near Lompoc", printed on the page without
                       a number; cluster = several gauges within 5 km, centroid),
                       gnis_* (named place on the page; gnis_oos_* = outside California),
                       b118_basin / b118_subbasin (groundwater basin named on the page)
  precision_km         approximate uncertainty of the point
  precision_class      precise | approximate | basin | conflict | unlocated
                       precise: suitable for subwatershed (HUC12) analysis
                       approximate: county / HUC8 scale
                       basin: a point inside the named groundwater basin; basin-scale only
                       conflict: independent location methods disagree by > 25 km with no
                         agreeing majority, or a named-place point lies > 30 km from every
                         NWIS gauge on the stream the entry names. Coordinates kept; do not
                         rely on them (excluded from the paper's maps and statistics)
  evidence_scope       page (all evidence on the table's own page) | document (direction
                       letters / meridian settled from elsewhere in the report)
  location_match       entry: location from one of the table's own metadata locations
                       none: unlocated
  location_ambiguous   True when the table's located points are > 5 km apart (the table
                       covers several sites)
  n_site_locations     number of distinct located points among the table's locations

SEARCH KEYS (blank when the location is too coarse)
  state, in_california  precise or approximate points (Census state boundaries)
  county                precise or approximate points (Census TIGER 2023 counties; also
                        counties of other states)
  huc8, huc8_name       California HUC8 subbasin; precise or approximate points
  huc12                 California HUC12 subwatershed; precise points only
  b118_basin_id, b118_basin_name
                        DWR Bulletin 118 groundwater basin/subbasin containing the point,
                        or (basin-class rows) the basin named on the page
  nwis_site_no, nwis_station_name, nwis_match_km, nwis_match
                        likely USGS NWIS site:
                        station_number_on_page: NWIS number printed on the page
                        station_name_on_page: NWIS station name printed on the page (no number)
                        nearest_named: nearest NWIS stream site within 5 km sharing a
                          name word
                        nearest_well: nearest NWIS groundwater site within 0.5 km
                          (candidate only)

DIGITIZATION QUALITY (heuristic; describes the digitized cells, not value accuracy)
  digitization_quality  poor: no data rows, > 90% empty cells, or > 5% cells with an OCR
                          letter-for-digit swap ("4,02C", "1O5", "2S0")
                        fair: > 1% such cells, or the table collapsed to one column
                        good: otherwise
  table_content         numeric | mixed | text (share of numeric-looking cells)
  frac_letter_zero      share of cells that are a lone "o"/"O". Old USGS typefaces print
                          zero this way (e.g. zero-flow days), so these values are easy to
                          recover; not counted against digitization_quality
  frac_ocr_suspect      share of cells with a letter-for-digit swap
  frac_empty            share of empty cells
  n_data_rows, n_cols   size of the digitized table
