Answer key review

Which table on the page

First lines of the digitizer's version, only to recognise the table. It may contain reading errors.
What the fields mean

One card per location the table reports data for, from this page only. Copy names, numbers and location words as printed. Blank = the page does not give it. "cannot tell" = it is on the page but cannot be read or decided. Fill every kind of location evidence the page prints; the grey Location and Location type at the top are picked from them automatically (coordinates, then well number, station number, station name, township-range-section, place, basin or area, county, state). Dates are those of the measurements in this table, as fine as printed: 1916, 1916-10 or 1916-10-01. Variables: discharge, runoff, gage_height, contents, elevation, water_level, well_yield, temperature, sediment, water_chemistry, precipitation, evaporation, well_construction, lithology, water_use, irrigated_area, other. Changes save when you leave a field.
